# pripara-arcade-mychara

캐릭터 이름과 외형 파츠를 선택해 **홍콩판 프리파라 아케이드의 로그인용 마이티켓 QR**을 만드는 웹앱입니다. 현재 버전은 **1.2.0**입니다.

캐릭터 한 명을 간단히 구성하는 데 초점을 맞췄습니다. 세이브 파일이나 게임 실행 파일을 불러오지 않고, 파츠 목록과 축소 이미지를 보며 이름·좋아요·외형을 선택할 수 있습니다. QR 생성은 브라우저 안에서 처리합니다.

## 주요 기능

- 눈매·헤어스타일·헤어컬러·아이컬러·피부색·안경·원포인트 선택
- 파츠 이름 검색과 선택 내용 미리보기
- 홍콩판에서 지원하는 파츠와 눈매·아이컬러 조합 검사
- 플레이어 코드 임의생성 또는 직접 입력
- 좋아요 직접 입력. 기본값은 20,000,000
- 생성한 마이티켓 QR의 PNG 저장과 이미지 복사
- 제공된 고정 시작용 QR을 보여 주는 **처음부터 마이캐릭터 생성하기** 팝업

의상은 기본 레슨 코디로 고정합니다. 파츠 이미지는 선택을 돕는 썸네일이며, 캐릭터의 3D 모델을 합성하거나 게임 화면을 렌더링하지 않습니다.

## 사용 방법

1. 이름을 입력합니다. 영문 대소문자, 숫자, `! ? ★ ☆ ♪`를 포함해 1~6자를 사용할 수 있습니다.
2. 원하는 파츠를 선택하고 좋아요를 입력합니다.
3. 플레이어 코드를 직접 입력하거나 **임의생성**을 선택합니다.
4. **홍콩판 QR 만들기**를 눌러 결과를 PNG로 저장하거나 복사합니다.

임의생성 모드에서는 첫 QR에 화면의 번호를 사용하고, 다시 만들 때 새 번호를 선택합니다. 직접 입력한 번호는 해당 페이지에서 반복 사용할 수 있습니다. 코드는 12자리로 표시하지만, 홍콩판 형식에서 그대로 유지할 수 있는 번호만 허용합니다. 0이나 지원 범위를 벗어난 번호는 오류로 안내합니다.

**처음부터 마이캐릭터 생성하기**는 별도로 제공된 시작용 PNG를 표시합니다. 현재 편집 중인 캐릭터나 브라우저 저장 내용을 삭제하지 않습니다.

## 구현 구조

별도 백엔드 없이 HTML·CSS와 JavaScript ES 모듈로 동작합니다.

| 구성 | 역할 |
| --- | --- |
| `src/app.mjs` | 파츠 선택 화면, 입력 검사, 선택 상태와 브라우저 저장 관리 |
| `src/codec.mjs` | 이름·외형·식별자 등을 HK App MyTicket v3의 121바이트 본문으로 구성하고 검증값과 바이트 재배열 처리 |
| `src/qr.mjs` | QR 라이브러리로 이진 바이트를 인코딩하고 Canvas로 PNG 생성 |
| `public/data/parts.json` | 파츠 이름, 홍콩판 값, 조합 호환성, 기본 코디 정보 |
| `public/images/` | 파츠 선택용 축소 이미지와 시작용 QR 이미지 |
| `vendor/` | QR 생성 라이브러리와 라이선스 |
| `tests/` | 숫자·이름 인코딩, QR 본문 대조, 저장 상태와 파츠 조합 검사 |

QR에는 선택한 이름·파츠, 기본 레슨 코디, 좋아요와 식별자가 들어갑니다. 좋아요와 랭크 포인트에는 같은 입력값을 기록합니다. 플레이 횟수 초기값은 **1**로 구성해 게임의 첫 플레이 초기화가 지정한 캐릭터 번호를 지우는 경우를 피하도록 했습니다. 이는 실제로 한 판 플레이했다는 이력을 복원한 값은 아닙니다.

기록 날짜는 구현에 지정된 호환용 고정값입니다. 생일·해금·등급 등 편집 항목에 없는 진행도는 새로 복원하지 않으며, 좋아요만으로 등급을 추정하지 않습니다.

## 데이터 보관과 범위

이름·파츠·좋아요·내부 UID는 같은 브라우저의 로컬 저장소에 보관합니다. 플레이어 코드는 저장하지 않으므로 페이지를 다시 열면 새 번호로 시작합니다. 내부 UID는 브라우저 저장 내용이 유지되는 동안 재사용하며, 표시되는 플레이어 코드와는 별도 값입니다.

캐릭터 정보나 QR을 서버로 전송하는 기능은 없습니다. 다른 기기와 정보를 동기화하지 않으며, 브라우저 데이터를 지우면 저장된 구성도 사라집니다. 임의생성한 번호가 모든 사용자를 통틀어 중복되지 않는지 확인하는 중앙 서버도 없습니다.

대상은 홍콩판 앱형 마이티켓입니다. 한국판·일본판의 모든 QR 형식이나 전체 세이브를 생성·복구하는 도구는 아닙니다. 자동 대조 검사는 데이터 구조를 확인하는 검사이며, 모든 게임 환경에서의 인식을 보증하지 않습니다.

게임 실행 파일·모델·대형 텍스처·사용자 세이브는 포함하지 않습니다. 관련 저작물의 권리는 각 권리자에게 있으며 비공식 호환 도구입니다. 포함 라이브러리의 출처와 라이선스는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)를 참고하세요.
