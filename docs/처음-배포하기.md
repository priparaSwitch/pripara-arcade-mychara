# 마이캐릭터 QR 사이트 배포하기

## GitHub Desktop에서 올리기

1. **File → Add local repository…**를 누릅니다.
2. 다운로드한 `pripara-arcade-mychara` 프로젝트 폴더를 선택합니다. 기존 `pripara-arcade-tomo`와 다른 프로젝트입니다.
3. **Publish repository**를 누릅니다.
4. 이름은 **pripara-arcade-mychara**로 둡니다.
5. 무료 GitHub Pages를 이용하려면 **Keep this code private**를 해제합니다. 프로그램과 파츠 썸네일이 공개됩니다. 사용자별 입력은 브라우저에만 남습니다.
6. **Publish repository**를 누른 뒤 **View on GitHub**를 엽니다.

프로젝트의 첫 커밋은 준비되어 있으므로 변경 사항이 없다면 따로 Commit할 필요가 없습니다.

## 사이트 켜기

1. 저장소 **Settings → Pages**로 들어갑니다.
2. **Source**를 **GitHub Actions**로 변경합니다.
3. **Actions → Test and deploy MyChara to GitHub Pages**를 선택합니다.
4. **Run workflow → main → Run workflow**를 누릅니다.
5. 초록 체크가 나오면 **Settings → Pages → Visit site**로 접속합니다.

주소 형식은 `https://GitHub아이디.github.io/pripara-arcade-mychara/`입니다. 실제 주소는 Pages 화면에 나온 링크를 사용하세요. 첫 Publish 때 Pages 설정이 없어 실패했더라도 설정을 바꾼 뒤 Run workflow로 다시 실행할 수 있습니다.

## 업데이트하기

프로젝트 파일을 수정한 뒤 GitHub Desktop에서 **Commit to main → Push origin**을 누릅니다. 자동 시험에 통과하면 새 버전이 배포됩니다. 프로그램을 실행할 PC나 NAS는 필요하지 않습니다.

## 캐릭터 정보 보관

이 사이트에는 로그인과 서버 보관함이 없습니다. 캐릭터 이름·파츠·좋아요와 내부 UID는 사이트 주소별로 현재 브라우저에 저장됩니다. 플레이어 코드와 직접 입력 모드는 저장하지 않으며, 페이지를 다시 열면 새 번호로 시작합니다. 브라우저 데이터를 삭제하거나 다른 기기를 이용하면 이전 캐릭터를 자동으로 가져오지 않습니다. 완성한 QR 이미지를 저장해 두세요.
